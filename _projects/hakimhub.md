## Overview

HakimHub is a healthcare information platform connecting patients with medical providers. I led the backend API development as part of the A2SV engineering team.

## Contributions

- Designed the full **database schema** for patients, providers, appointments, and medical records.
- Implemented **REST API endpoints** with Node.js / Express.js / NestJS following RESTful conventions.
- Integrated third-party services: authentication (JWT + OAuth), transactional email, and real-time messaging.
- Improved query performance by **25%** by rewriting N+1 queries, adding strategic indexes, and redesigning join-heavy schema relationships.

## Stack

`NestJS` · `PostgreSQL` · `TypeORM` · `JWT` · `SendGrid` · `Socket.io`
